'''It's a network traffic inspector — it watches all the data flowing in and out of your computer in real time.
When you run it, it sits on your network interface and intercepts every packet passing through. For each one it figures out: what protocol it is (TCP, UDP, DNS, ARP, etc.), where it came from, where it's going, what port, and what's inside. It prints a live feed to your terminal as packets arrive.
When you stop it (Ctrl+C), it prints a summary showing which protocols dominated, which IPs were most active, and which ports saw the most traffic.
The dashboard widget above simulates what that live feed looks like — the real script produces the same data in your terminal.
Why it's useful as a portfolio project: it shows you understand how the internet actually works at a low level — packets, protocols, layers — rather than just writing web apps. It's the kind of tool security engineers use to diagnose network issues, spot suspicious traffic, or understand what an application is actually doing on the wire.
